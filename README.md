(API `26.3.build.200-stable`).

The legacy GUI and duel helpers compile against the current configuration API.
The existing entry point registers the item/potion listener; command handlers
and GUI click actions described below are not implemented by this entry point.

🔥 Main Features

🔨 Mace Control: Maces can be completely disabled. When disabled: ❌ Pick up → deleted ❌ Inventory → deleted ❌ Use → deleted ❌ Attack → deleted

👉 No player can exploit the mace

💪 Strength Limit

You can set the maximum Strength level:

/setstrength 1 Anything above this level will be: ❌ blocked ❌ unusable ❌ automatically removed

👉 Prevents overpowered potions in PvP

☠️ Weakness Control

Weakness can be completely disabled:

/toggleweakness When disabled: ❌ Potions will not work ❌ Effect will be removed

 Ntherite Control: Netherite can be completely disabled. When disabled: ❌ Pick up → deleted ❌ Inventory → deleted ❌ Use → deleted ❌ Attack → deleted

 GUI Menu:

 you can toggle everything from the GUI Menu
 
🎮 Commands: /togglemace → Mace on/off /setstrength <level> → Set Strength Limit /toggleweakness → Weakness on/off
